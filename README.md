# Landing Pages - Médica Ginecologista

3 modelos de landing pages criados para uma médica ginecologista, utilizando uma paleta de cores inspirada em tons terrosos (sage green, terracotta e neutros) e baseados na estrutura do site de referência.

## 🎨 Modelos Disponíveis

### Modelo 1 - Design Minimalista
- Layout limpo e direto
- Foco em tipografia e espaçamento
- Cards simples com hover sutil
- Design responsivo e elegante

### Modelo 2 - Design com Cards Visuais
- Interface com mais elementos visuais
- Sistema de abas para tratamentos
- Cards de depoimentos com destaque
- Layout em grid com animações

### Modelo 3 - Design Moderno e Assimétrico
- Layout assimétrico e moderno
- Números grandes como elementos visuais
- Design diferenciado com elementos decorativos
- Experiência visual mais impactante

## 🎨 Paleta de Cores

Baseada na imagem de referência, utilizando:

- **Sage Green (claro)**: `#E8F4E8`
- **Sage Green (médio)**: `#A8C5A8`
- **Sage Green (escuro)**: `#7A8B7A`
- **Sage Green (ebony)**: `#566048`
- **Terracotta (claro)**: `#E8B8A3`
- **Terracotta (médio)**: `#B07146`
- **Terracotta (escuro)**: `#8B5635`
- **Neutros**: `#F5F3F0`, `#E8E3D8`, `#D4C5B0`

## 🚀 Instalação

1. Instale as dependências:
```bash
npm install
```

2. Execute o projeto em modo de desenvolvimento:
```bash
npm run dev
```

3. Acesse no navegador:
```
http://localhost:5173
```

## 📦 Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a build de produção
- `npm run preview` - Visualiza a build de produção
